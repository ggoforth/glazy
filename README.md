# glazy

Spinning, photoreal-ish 3D donuts in a `<canvas>`, powered by [Three.js](https://threejs.org).

![glazy hero](docs/media/hero.gif)

> A clean, configurable, drop-in library that renders a glazed, spinning 3D donut.
> Pick a preset, a shape, a topping — or wire it up to live controls.

The images in this README (`docs/media/*`) are generated by opening the example
pages under [`examples/`](examples/) in a browser. The `controls.html` page has a

## Install

**npm** (Three.js is a peer dependency, so install it alongside):

```sh
npm i glazy three
```

**Script tag / CDN** — load Three.js **first**, then the UMD bundle:

```html
<script src="https://unpkg.com/three@0.160.0/build/three.min.js"></script>
<script src="https://unpkg.com/glazy/dist/glazy.umd.js"></script>
```

## Quick start (global / `<script>`)

The UMD bundle exposes a global `Glazy`. Three.js must be loaded first as the
global `THREE`.

```html
<!doctype html><html><head><meta charset="utf-8"><title>glazy · global</title>
<style>body{margin:0;background:#faf7f2}.donut-stage{position:relative;width:100vw;height:100vh}</style></head>
<body>
  <div class="donut-stage" id="stage"></div>
  <script src="https://unpkg.com/three@0.160.0/build/three.min.js"></script>
  <script src="../dist/glazy.umd.js"></script>
  <script>new Glazy.DonutRenderer(document.getElementById('stage'), { preset: 'strawberry' });</script>
</body></html>
```

See [`examples/global.html`](examples/global.html).

## Quick start (ESM)

`three` is a **peer dependency** — import it yourself and pass it in (or rely on a
global `THREE`). Here it is resolved through an import map.

```html
<!doctype html><html><head><meta charset="utf-8"><title>glazy · esm</title>
<style>body{margin:0;background:#faf7f2}#stage{position:relative;width:100vw;height:100vh}</style>
<script type="importmap">{ "imports": { "three": "https://unpkg.com/three@0.160.0/build/three.module.js" } }</script>
</head><body>
  <div id="stage"></div>
  <script type="module">
    import * as THREE from 'three';
    import { DonutRenderer } from '../dist/glazy.esm.js';
    new DonutRenderer(document.getElementById('stage'), { three: THREE, shape: 'old-fashioned', frost: 0x8fbf6f });
  </script>
</body></html>
```

In a bundler-based project it's simply:

```js
import * as THREE from 'three';
import { DonutRenderer } from 'glazy';

const donut = new DonutRenderer('#stage', { three: THREE, preset: 'blueberry' });
```

See [`examples/esm.html`](examples/esm.html).

## Data attributes (auto-init)

Mark any element with `data-donut` and call `autoInit()` — the UMD build does this
automatically on `DOMContentLoaded`. The parsed `data-*` attributes **are** the
explicit options for that instance. Multiple instances per page are supported.

| Attribute | Maps to option | Example |
|---|---|---|
| `data-donut` | marker (required) | `<div data-donut></div>` |
| `data-shape` | `shape` | `data-shape="bar"` |
| `data-preset` | `preset` | `data-preset="strawberry"` |
| `data-frost` | `frost` | `data-frost="#3a73cf"` |
| `data-dough` | `dough` | `data-dough="#df9f48"` |
| `data-frost-finish` | `frostFinish` | `data-frost-finish="frosting"` |
| `data-topping` | `topping` | `data-topping="nuts"` |
| `data-count` | `toppingCount` | `data-count="80"` |
| `data-fill` | `fillLight` | `data-fill="#e6f0ff"` |
| `data-seed` | `seed` | `data-seed="42"` |
| `data-spin-speed` | `motion.spin.speed` | `data-spin-speed="0.01"` |
| `data-spin-direction` | `motion.spin.direction` | `data-spin-direction="-1"` |
| `data-wobble` | `motion.wobble.enabled` | `data-wobble="false"` |
| `data-bob` | `motion.bob.enabled` | `data-bob="false"` |
| `data-mouse-lean` | `motion.lean.enabled` | `data-mouse-lean="false"` |
| `data-lean-strength` | `motion.lean.strength` | `data-lean-strength="0.4"` |
| `data-lean-source` | `motion.lean.source` | `data-lean-source="element"` |

Booleans follow the usual rule: `"true"` / `""` (bare attribute) / present → `true`;
`"false"` / `"0"` → `false`.

```html
<div data-donut data-preset="strawberry"></div>
<div data-donut data-preset="chocolate" data-shape="bar"></div>
<script src="https://unpkg.com/three@0.160.0/build/three.min.js"></script>
<script src="../dist/glazy.umd.js"></script>
<!-- UMD auto-inits [data-donut] on DOMContentLoaded -->
```

See [`examples/autoinit.html`](examples/autoinit.html).

## Options

`defaults < preset < explicit options`. Where a flat alias and the structured
`motion` object both set the same value, the structured `motion` wins. Colors
accept `0xRRGGBB` numbers, `'#rrggbb'`, `'rrggbb'`, or `'0xRRGGBB'` strings;
invalid values fall back to the default with a single `console.warn`.

| Option | Type | Default | Notes |
|---|---|---|---|
| `three` | THREE \| null | `null` | injected; falls back to global `THREE` |
| `shape` | string | `'ring'` | `'ring'` \| `'bar'` \| `'old-fashioned'` |
| `preset` | string \| null | `null` | merged **under** explicit options |
| `dough` | color | `0xdf9f48` | accepts `0xRRGGBB`, `'#rrggbb'`, `'rrggbb'`, number |
| `frost` | color | `0xed4359` | glaze/frosting color |
| `frostFinish` | string | `'glaze'` | `'glaze'` \| `'frosting'` |
| `frostRoughness` | number | finish-dependent | clamped `[0,1]` |
| `frostClearcoat` | number | finish-dependent | clamped `[0,1]` |
| `glazeTextureScale` | number | `1` | surface-relief strength |
| `doughRoughness` | number | `0.82` | clamped `[0,1]` |
| `doughGrain` | number | `1` | grain bump intensity |
| `crust` | bool \| number | `true` | crust-tone strength (`true` = default) |
| `fillLight` | color | `0xffe6ef` | fill-light tint |
| `topping` | string | `'sprinkles'` | `'sprinkles'` \| `'nuts'` \| `'none'` |
| `sprinkleColors` | color[] | brand palette | |
| `nutColors` | color[] | tan→walnut | |
| `toppingCount` | int | `150` | clamped `[0, 2000]` |
| `motion` | object | see below | structured per-behavior motion/interaction config |
| `spinSpeed` | number | `0.004` | flat alias → `motion.spin.speed` |
| `wobble` | bool | `true` | flat alias → `motion.wobble.enabled` |
| `mouseLean` | bool | `true` | flat alias → `motion.lean.enabled` |
| `reducedMotion` | `'auto'` \| bool | `'auto'` | live-responsive via `matchMedia` |
| `pixelRatioCap` | number | `2` | |
| `seed` | int \| null | `null` | set → deterministic placement & colors |
| `materials` | object | `{}` | deep-override escape hatch: `{ dough:{…}, frost:{…} }` |

### `motion`

Each behavior is independently toggleable and tunable. Every sub-object also
accepts a boolean shorthand (`spin: false` = off, `spin: true` = defaults).

```js
motion: {
  spin:   { enabled: true, speed: 0.004, direction: 1 },                    // turntable yaw about the hole axis; direction ±1
  wobble: { enabled: true, amplitude: 0.05, speed: 0.9 },                   // undulating sway: oscillating pitch + roll
  bob:    { enabled: true, amplitude: 0.045, speed: 1.1 },                  // vertical float / drift up-down
  lean:   { enabled: true, strength: 0.16, ease: 0.045, source: 'window' }, // eased tilt toward pointer
}
```

| Behavior | Knobs | Effect |
|---|---|---|
| `spin` | `enabled`, `speed`, `direction` (±1) | turntable yaw about the hole axis |
| `wobble` | `enabled`, `amplitude`, `speed` | oscillating pitch + roll sway |
| `bob` | `enabled`, `amplitude`, `speed` | vertical float / drift up-down |
| `lean` | `enabled`, `strength`, `ease`, `source` | eased tilt toward the pointer |

- **`lean.source`** — `'window'` (default; tilts toward the pointer anywhere on the
  page) or `'element'` (only while the pointer is over the donut's own element,
  better when several donuts share a page).
- **`lean.ease`** is the smoothing factor (default `0.045`): lower = lazier follow,
  higher = snappier.
- **Reduced motion** suppresses **all four** behaviors (lean included) and renders a
  single static frame.

## Three.js compatibility

glazy requires **`three >= r160`** and is **tested against `three` r160.0**.

It uses the modern Three.js color-space API (`renderer.outputColorSpace =
THREE.SRGBColorSpace`, and per-texture `colorSpace`), which replaced the legacy
`outputEncoding` / `sRGBEncoding` API removed around r150–r160. All version-sensitive
color handling is isolated in `src/three-compat.js` (`configureColorSpace`) and
`src/materials/textures.js` (color maps tagged sRGB; normal maps left linear), so
the rest of the codebase never touches version-sensitive color APIs.

If Three.js can't be resolved (no injected `three` and no global `THREE`), glazy
logs **one** warning and returns an **inert instance** whose methods are safe
no-ops — it never throws.

## Lifecycle / SPA

```js
const donut = new DonutRenderer('#stage', { three: THREE, preset: 'strawberry' });

donut.setOptions({ frost: 0x3a73cf, topping: 'nuts', shape: 'bar' }); // live update
donut.screenshot();   // -> PNG dataURL (preserveDrawingBuffer is on)
donut.destroy();      // full GPU + listener cleanup
```

- **Call `destroy()` on unmount.** It cancels the rAF loop, disconnects the
  `ResizeObserver` and `IntersectionObserver`, removes the pointer and `matchMedia`
  listeners, walks the scene disposing every geometry / material / texture / render
  target, disposes the renderer, removes the canvas, and nulls references — no leaks.
  In a React component, call it from the effect cleanup; in Vue, from `onUnmounted`.
- **`setOptions` rebuilds only what changed.** Cheap changes (e.g. `spinSpeed`) touch
  only the animation; recoloring touches the material; changing `shape` rebuilds the
  body. It diffs the incoming patch rather than tearing down the whole scene.
- **Decorative by default.** The canvas is given `aria-hidden="true"`; treat the
  donut as a decorative element and provide text alternatives elsewhere if it conveys
  meaning.
- **Reduced motion.** `prefers-reduced-motion: reduce` renders a single static frame
  and suppresses all motion; a `matchMedia` listener responds live. The
  `reducedMotion` option (`true` / `false`) overrides auto-detection.

## Performance

- **Pixel-ratio cap.** `pixelRatioCap` (default `2`) bounds the device pixel ratio so
  high-DPI displays don't render at punishing resolutions.
- **Off-screen pause.** An `IntersectionObserver` pauses the rAF loop when the canvas
  scrolls off-screen and resumes on re-entry, saving battery and GPU.
- **Element-based sizing.** A `ResizeObserver` on the target element (not
  `window.resize`) keeps the canvas crisp without global listeners.
- **Deterministic `seed`.** Set `seed` to make topping placement and color selection
  fully reproducible (mulberry32 PRNG threaded through the shape and topping
  factories) — handy for visual regression and stable thumbnails.

glazy

Spinning 3D donuts in a <canvas>, rendered with Three.js.

Studio Presets Global build No-build / CDN GitHub

Drop it into any static page with an import map, no bundler required:

<script type="importmap">
{ "imports": { "three": "https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js" } }
</script>
<script type="module">
  import { autoInit } from 'https://cdn.jsdelivr.net/gh/ggoforth/glazy@v0.1.1/dist/glazy.esm.js';
  autoInit();
</script>

<div data-donut data-preset="blueberry" data-topping="nuts"></div>

MIT licensed. Shapes: ring, bar, old-fashioned, cruller. Toppings: sprinkles, nuts, coconut.
